# chains-ai L3 决策骨架（蒸馏自 reverse-skill llm-security/SKILL.md；仅限安全验证）
- 场景:目标工作授权门禁|判据:明确 auth.status=granted，资产/表面/活动均在范围内，且有合法 network_profile 或明确授权的离线样本；若拟执行仓库脚本，须先披露准确命令及副作用并取得用户单独明确同意|转向:任一缺失仅做被动/只读分析；不得强制或绕过门禁
- 场景:AI 攻击面映射|判据:枚举所有 LLM 入口(聊天/文件/API 参数/邮件处理)、Agent 注册的工具(send_email/query_db/exec 等)与数据流(输入→检索上下文→工具调用→输出)；确认是否有人在回路审批及触发条件|转向:下游被 LLM 输出直接消费的 XSS/SQLi/命令执行转 web；工具触达云/内网转 cloud/pivot
- 场景:提示注入与系统提示词提取(LLM01/LLM07)|判据:按直接覆盖→角色扮演→编码绕过(Base64/同形字/零宽)→多轮渐进→间接注入(RAG/网页/邮件嵌入隐藏指令)递进；系统提示词用级联提取(复述/翻译/JSON)验证，canary token 判泄露|转向:能让 Agent 执行越权动作转工具滥用；仅信息泄露按敏感度定级
- 场景:工具滥用与记忆投毒(ASI02/03/05/06)|判据:测越权组合调用、人在回路绕过(紧急/CEO 等待借口)、经工具参数的 Shell/代码注入；向知识库与长期记忆注入恶意文档测 RAG 检索是否被污染，验证检索时(而非仅存储时)权限|转向:投毒可操控输出或动作则串成可利用链；最小权限不足仅记为配置缺陷
- 场景:Evidence→Finding→Path 与提报|判据:Evidence 记录 ID/来源/SHA-256(样本或制品哈希，无则标 n/a)/复现条件与结果；Finding 引证验证受影响点、根因与影响、校验状态与置信度及修复建议；Path 连接起点→验证步骤→目标及证据 ID|转向:输出脱敏 CVE/CNVD/bounty 报告，移除真实凭据/隐私，区分候选与已验证，明确未证实项
